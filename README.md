# NLP Pipeline - Movie Review (Roll No. 57)

MCA | Artificial Intelligence (MCS 3014) | Innovative Assessment, Group 5

Notebook `57_NLP_Pipeline.ipynb` runs on one movie review:

**Part I:** text type, sentence segmentation, word tokenization, lowercase and punctuation/number removal, stop-word removal.
**Part II:** stemming, lemmatization, Bag-of-Words, TF-IDF, sentiment classification (VADER plus evidence from the text).

## How to run
Open the notebook in Google Colab and choose Runtime > Run all. Libraries: nltk, scikit-learn, pandas.
